# DocDesk: correct it once, the docs fix themselves

DocDesk is a teammate that lives in your team chat through [Switch](https://github.com/sandbox-quantum/switch).
It answers questions from your repo with citations to files and commits. When someone corrects it, it checks
the correction against the code, hands the doc gap to a coding agent in a linked room, and closes the loop in
the original thread once a human approves the fix.

Built for the Flip the Switch hackathon (Track 01, Best Business Workflow). Work in progress.
